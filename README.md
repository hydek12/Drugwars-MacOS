# DrugwarApp (TI-83 Edition for macOS)

A native macOS SwiftUI recreation of the classic TI-83 calculator game *Drug Wars*, complete with an olive-green dot-matrix LCD interface, interactive calculator keypad, and full keyboard support.

## Features

* **Authentic TI-83 Mechanics:** Preserves the original 30-day cycle, street price fluctuations, compound loan shark debt (10%/day), bank interest (6%/day), trenchcoat capacity upgrades, and subway random events.
* **Retro Calculator UI:** Styled after the classic monochrome LCD screen with clickable keypad buttons (`0`–`9`, `ENTER`, `CLEAR`, `MAX`, and `MENU`).
* **Full Keyboard Support:** Play seamlessly using your Mac's number keys, `Return`/`Enter`, and `Delete`/`Esc`.
* **Apple Silicon Native:** Built in pure Swift and SwiftUI for modern macOS systems.

## Controls

| Input | Action |
| :--- | :--- |
| **`0` – `9`** | Select menu options, destinations, or enter quantities |
| **`Return` / `Enter`** | Confirm selection or advance past event screens |
| **`MAX` Button** | Auto-fill maximum affordable quantity, inventory, or cash |
| **`Delete` / `Esc` / `CLEAR`** | Backspace digits or return to the previous menu |
| **`MENU` Button** | Return immediately to the main action menu |
